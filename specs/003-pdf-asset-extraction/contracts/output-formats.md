# Output Format Specifications

**Feature**: PDF Asset Extraction Tool
**Contract Type**: JSON Schemas and Output Formats
**Created**: 2026-02-22

---

## Overview

This document defines the JSON schemas for all file outputs generated by the PDF extraction tool. All output files use JSON format for structured data and HTML for human-readable reports.

**JSON Style Guide**:
- Use 2-space indentation
- Sort object keys alphabetically (exceptions noted)
- Use ISO 8601 format for timestamps (`YYYY-MM-DDTHH:mm:ssZ`)
- Use UUIDs (v4) for unique identifiers

## 1. PDF Catalog

**File Path**: `data/pdfs/catalog.json`
**Generated By**: `download` command
**Purpose**: Inventory of all downloaded PDFs

### Schema

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": ["pdfs", "metadata"],
  "properties": {
    "pdfs": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["filename", "file_path", "content_type", "page_count", "file_size", "download_timestamp"],
        "properties": {
          "content_type": {
            "type": "string",
            "enum": ["module_suspect", "module_investigator", "penalties", "backgrounds", "print_play"]
          },
          "download_timestamp": {
            "type": "string",
            "format": "date-time"
          },
          "file_path": {
            "type": "string"
          },
          "file_size": {
            "type": "integer",
            "minimum": 0
          },
          "filename": {
            "type": "string"
          },
          "page_count": {
            "type": "integer",
            "minimum": 1
          }
        }
      }
    },
    "metadata": {
      "type": "object",
      "required": ["total_pdfs", "total_size_bytes", "catalog_generated"],
      "properties": {
        "catalog_generated": {
          "type": "string",
          "format": "date-time"
        },
        "total_pdfs": {
          "type": "integer",
          "minimum": 0
        },
        "total_size_bytes": {
          "type": "integer",
          "minimum": 0
        }
      }
    }
  }
}
```

### Key Features

- **Self-contained**: All images embedded as base64 (no external file dependencies)
- **Offline-capable**: No JavaScript frameworks or CDN dependencies
- **Responsive**: CSS Grid layout works on desktop and tablet
- **Color-coded status**:
  - Green: Success rate >= 95%, confidence >= 0.9
  - Yellow: Success rate 80-95%, confidence 0.7-0.9
  - Red: Success rate < 80%, confidence < 0.7
- **Metadata included**: Coordinates, confidence scores, extraction methods for traceability

## Contract Tests

### General Schema Validation

All JSON outputs must pass JSON Schema validation:

```python
import json
import jsonschema

def test_catalog_schema_valid():
    """Verify catalog.json matches schema"""
    with open('data/pdfs/catalog.json') as f:
        catalog = json.load(f)

    with open('schemas/catalog.schema.json') as f:
        schema = json.load(f)

    jsonschema.validate(instance=catalog, schema=schema)  # Raises if invalid

def test_labels_schema_valid():
```

### Round-trip Serialization

All outputs must be JSON-serializable and deserializable without data loss:

```python
def test_extraction_metadata_round_trip():
    """Verify extraction metadata can be serialized and deserialized"""
    with open('data/output/metadata/extraction_metadata.json') as f:
        original = json.load(f)

    # Serialize and deserialize
    json_str = json.dumps(original, indent=2)
    reloaded = json.loads(json_str)

    assert original == reloaded

def test_timestamps_iso8601_format():
    """Verify all timestamps use ISO 8601 format"""
    with open('data/pdfs/catalog.json') as f:
        catalog = json.load(f)

    for pdf in catalog['pdfs']:
        ts = pdf['download_timestamp']
        # Should parse as ISO 8601
        datetime.fromisoformat(ts.replace('Z', '+00:00'))  # Raises if invalid
```
